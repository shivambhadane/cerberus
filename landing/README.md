# Cerberus Landing Page

Cerberus landing page built on the high-fidelity interactive design system of [Outtake.ai](https://www.outtake.ai/?ref=saaspo.com) in `landing/index.html`.

## Viewing the Page

You can view it directly by opening `landing/index.html` in your web browser, or by serving it locally:

```bash
python3 -m http.server 5180 --directory landing
```

Then visit **http://localhost:5180**.
